# Research — Kculture

Use this directory for strategy hypotheses, mechanics verification, opponent archetypes, economy notes, and metagame observations.

## Suggested note structure

Each research note should state:

1. question/hypothesis;
2. known official mechanic(s);
3. inferred mechanism, clearly marked as inference;
4. expected measurable effect;
5. experiment needed;
6. outcome and decision.

## Initial research tracks

- action-efficiency accounting
- crop economics and lifecycle timing
- fertilizer economics
- farm-hand hiring/payback
- land expansion timing
- livestock pathways
- inventory/shed logistics
- market-price dynamics
- opponent archetype detection
- adaptive production/selling
- endgame liquidation/terminal-value behavior
- robust two-agent final portfolio

Do not place inferred mechanics in `docs/COMPETITION.md` until verified.
